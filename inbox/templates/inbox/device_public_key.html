Add the public key to UniFi Network

  1. Copy the public key below.
  2. Open your controller’s UniFi Network application, then Settings → Devices → Device Updates and Settings → Device SSH Settings.
  3. Enable Device SSH Authentication if needed. Under SSH Keys, select Add SSH Key, enter a name such as UniFi SMS, and paste the entire public key. Save it and apply the changes.
  4. Wait for the settings to be applied to your LTE Pro. {% if step == 'access' %}Return here, select Continue, then Check connection.{% else %}Then select Check connection below.{% endif %}
Using an older controller?

Open Settings → System → Advanced → Device Authentication → SSH Keys to add the public key.
